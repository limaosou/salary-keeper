# 工资通 · 考勤计薪核对小程序

基于考勤打卡与绩效考核，帮你清晰核对每个月的工资条。纯前端实现（原生 HTML/CSS/JS），数据全部存在本机 localStorage，**不上传任何服务器**，零依赖、双击即用。

## 功能对照

| 需求 | 实现 |
|---|---|
| 地理围栏自动打卡 | **「打开即校准」模式**：每次打开/回到前台取一次定位，自动对齐签到与签退状态。不需要页面常驻，iOS 锁屏冻结也不影响（由系统自动化唤起） |
| 白班/夜班模式 | 今日页右上角一键切换；夜班按「时段 × 补助」或「每班固定额」计 |
| 绩效计薪 | 支持按日绩效（每日填）或整月统一系数，作用于正常工时工资 |
| 首页实时今日已赚 | 打卡中每 15 秒按当前时刻实时跳动，未签退段持续累计 |
| 月度汇总与核对 | 工资条式呈现：지급합계（应发）→ 逐项 공제（社保/个税）→ 차인지급액（实发）；输入工资条 실수령 自动比对差额 |
| **考勤月历** | 一天一格，按颜色标注正常/迟到/早退/缺卡/旷工/请假/休息；**状态全部由打卡数据自动判定**，无需人工录入；点日期可手工补签、登记请假、标记休息日 |

## 全自动打卡（不用开着页面）

iOS 的 Safari / PWA 一旦锁屏或切到后台，系统会**冻结网页的定位和脚本**——这是苹果的系统级限制，任何网页代码都绕不过去。所以「让页面一直开着自动打卡」在 iPhone 上行不通。

本工具的做法是**换一种触发方式**：不做持续监听，改成**每次被唤起时取一次定位把状态对齐**，再让 iOS 自带的**快捷指令自动化**在「到达 / 离开公司」时自动打开本页。于是：

- 你到公司 → 系统触发「到达」→ 自动打开本页 → 取一次定位 → 在围栏内 → **自动签到**
- 你离开 → 系统触发「离开」→ 自动打开本页 → 取一次定位 → 不在围栏内 → **自动签退并结算当日**
- 全程不需要打开 APP、不需要点任何按钮，一个月看一次【月薪】即可

### iPhone 配置步骤（一次性约 3 分钟）

1. Safari 打开线上地址 → 分享 → **添加到主屏幕**
2. 设置 → 隐私与安全性 → 定位服务 → Safari 网站 → **始终允许**
3. 快捷指令 App → 新建快捷指令「工资通打卡」→ 添加操作 **打开 URL**
4. 填入 App【设置】页里一键复制的那个地址（形如 `https://limaosou.github.io/salary-keeper/index.html`）
5. 快捷指令 App → 顶部 **自动化** → 新建 → **到达**（选公司地点）→ 选刚才的快捷指令
6. 再新建一个 **离开** 同一地点的自动化
7. 两个自动化都设为 **「立即运行」**（不要等询问）
8. 回 App【设置】点 **「测试一次自动打卡」** 验证

围栏半径建议 **150–300 米**：iOS 的到达/离开判定本身有几十米误差，太小会漏触发，太大会提前触发。

### 防误打卡

- **离场防抖**：签退后 N 分钟内（默认 30，可在设置调）不会因围栏边缘 GPS 抖动立刻重签
- **精度保护**：GPS 精度差（>150 米）时自动收紧判定半径
- **未配置坐标不打卡**：没设公司坐标时校准直接跳过，不会产生脏数据
- **异常记录**：定位被拒等异常会记到【设置 → 运行异常记录】，月底一眼能看到该不该人工补

### Android / 其他浏览器

Android Chrome 后台也会限制定位，但比 iOS 宽松，且 Tasker 等自动化工具可以直接调用本页地址，效果同样稳定。桌面浏览器打开时仍可用「持续监听」模式实时打卡。

## 考勤月历

【考勤】页顶部是月历，一天一格，状态**全部由已有打卡数据自动判定**，不需要人工录入。

### 状态判定规则

判定优先级：**休息日/请假 > 未来日期 > 旷工/待出勤 > 缺卡 > 迟到/早退 > 正常**

| 状态 | 颜色 | 判定条件 |
|---|---|---|
| 正常 | 绿 | 签到 ≤ 上班+宽限，且签退 ≥ 下班−宽限 |
| 迟到 | 黄 | 签到晚于「上班 + 迟到宽限」 |
| 早退 | 橙 | 签退早于「下班 − 早退宽限」 |
| 迟到早退 | 深橙 | 两者兼具 |
| 缺卡 | 紫 | 有签到但没签退（且当天已过） |
| 旷工 | 红 | 已过去的工作日无任何记录 |
| 请假 | 蓝 | 已登记请假 |
| 休息 | 灰 | 周休日 / 法定节假日 / 手动标记 |
| 待出勤 | 金虚线 | **今天**还没打卡（不误判为旷工） |
| 未来 | 灰虚线 | 尚未到来的工作日 |

两个刻意的取舍：

- **休息日与请假优先于「未来」**：月底的周日和提前请好的年假会正常显示为「休」「假」，这样月历才能用来规划排班；否则全被「未来」盖住，看不到本月哪天休息。
- **今天不判旷工**：上班路上打开 app 不会一进门就被记旷工，显示为「待出勤」。

### 手工补签

点任意非未来日期打开面板，可：

- **补签到 / 补签退**：打开时按当下情形自动选中合理动作（没签到→补签到；有签到未签退→补签退），默认时间取标准上下班时间
- **登记请假**：연차 年假 / 병가 病假 / 경조사 婚丧假 / 기타 其他，再点一次即取消
- **标记休息日**：临时调休、公司放假等，再点一次即取消
- **撤销补签**：补签记录逐条留痕（时间 + 备注 + 操作时刻），可一键撤销，撤销时**连带回滚**该次补签产生的打卡数据

合法性校验（任一不满足即拒绝并提示原因）：

1. 不能为未来日期补签
2. 补签时间须落在当日 00:00–23:59 之间（跨日会被拒）
3. 补签时间不能超过当前时刻
4. 已有签到记录时不能重复补签到
5. 补签退必须晚于签到时间，且当日存在未签退的签到
6. 补签类型必须是签到或签退

补签成功后，月历、状态统计、每日记录、首页已赚、月薪页**全部即时重算**，日历格子上会出现小圆点标记该日有补签。

### 出勤规则配置

【设置】→「출퇴근기준 · 出勤判定」可调：标准上下班时间、迟到/早退宽限分钟数、每周休息日（点选切换）、法定节假日列表。改动后月历即时重判。

## 快速开始

1. 首次使用进【设置】：
   - 【직원档案】填 사번（工号）、성명（姓名）、부서（部门）、직급（职位）、입사일（入职日）
   - 【근로조건】填 시급（时薪）、월급여시간（月计薪工时，默认 176）、주당일수（周工作天数）、일근로시간（每日工时）
   - 【초과근로】加班倍率（韩国默认 1.5）、奖金倍率
   - 【소득세】所得税模式：按工资条金额手填（`manual`，最准）或按累进税率估算（`auto`）
   - 【지급항목】【공제항목】核对津贴与扣除项
   - **到公司门口点「📍 获取当前位置为公司坐标」**（半径默认 200 米，误触发就加大）
2. 日常使用：进公司自动签到、离公司自动签退；也可随时手动签到/签退兜底。
3. 月底进【月薪】页：看工资条式汇总，输入工资条上的 실수령 금액点「核对」，一致/差额一目而过。

## 计薪规则（韩国月薪制）

数据默认按 2026-09 工资条配置，**三个关键数字可完整复现**。

### 支给（应发）

| 项目 | 公式 | 示例（2026-09） |
|---|---|---|
| 기본급（基本工资） | 월급여시간 × 시급 = 176h × 10,470 | 1,842,720 |
| 기업급여(주수)（周薪） | 주당일수 × 일근로시간 × 시급 = 4 × 8 × 10,470 | 335,040 |
| 현장근로수당（加班费） | 시급 × 1.5 × 초과근로시간 = 10,470 × 1.5 × 39.34h | 617,840 |
| 실액수당（实务补贴） | 固定额 | 366,450 |
| 직무개발비（职务开发费） | 固定额 | 192,000 |
| **지급합계** | 合计 | **3,354,050** |

> 월급여시간 176h 是由 `기본급 ÷ 시급` 反推的韩国法定月计薪工时；시급 为时薪时，基本工资不随当月实际出勤变动，缺勤/加班在津贴与加班费里体现。

### 扣除（공제）

保险基数：**보험료기준 = 기본급 + 실액수당 = 1,842,720 + 366,450 = 2,209,170**

| 项目 | 计算方式 | 示例 |
|---|---|---|
| 국민건강보험 | 基数 × 7.379242% | −163,020 |
| 장기보험（退休） | 基数 × 5.620663% | −124,170 |
| 고용보험（雇佣） | 基数 × 1.406863% | −31,080 |
| 기수사회（工会会费） | 固定 50,000 | −50,000 |
| 장기요금보험료（长期护理） | 基数 × 0.738286% | −16,310 |
| 소득세（所得税） | `manual` 取工资条实发税额 | −119,880 |
| 지방소득세（地方税） | 所得税 × 10%，十位向下取整 | −11,980 |
| **공제합계** | 合计 | **−516,440** |

**차인지급액（实发）= 3,354,050 − 516,440 = 2,837,610**

> 社保费率精确到 6 位小数——用 3 位小数会带来 ±5~7 韩元的偏差，无法与工资条对齐。
> 地方所得税的「十位向下取整」也是工资条的实际规则：119,880 × 10% = 11,988，但工资条按十位截断为 11,980。
> 所得税金额无法从纸面反推（工资条的 119,880 对应的应税所得与常见口径都不符），因此默认 `manual` 直接采用工资条实发税额，同时保留 `auto` 累进估算模式供估算时参考。

### 工时口径

- 当日工时 = 签退 − 签到 − 休息扣除（默认 60 分钟午休，可调）
- 加班工时 = 当日工时 − 일근로시간（超出每日标准工时的部分）
- 夜班工时 = 与夜班时段重叠的时长
- 跨午夜班次（如 22:00–06:00）自动拆分计算
- 休息日不计薪；往日忘记签退的记录，在【考勤】页点该日期可按 23:59 补结算

## 已知限制

- **iOS 锁屏会冻结网页定位**（系统级限制，网页无法绕过）：所以自动打卡改为「系统自动化唤起页面 → 取一次定位对齐状态」，而不是持续监听。若未配置快捷指令自动化，页面只能在你手动打开时校准
- iOS 的到达/离开判定由系统完成，有几十米到几百米误差、且滞后于真实移动（一般 1–5 分钟）；围栏半径太小会漏触发，太大会提前触发
- H5 定位在 localhost 或 HTTPS 下可用，http + 非 localhost 会被浏览器拒绝（线上地址是 HTTPS，不受影响）
- 数据存在本机浏览器/APP 内，清缓存前请先在【设置】导出备份 JSON
